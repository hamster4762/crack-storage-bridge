# 크랙 저장소 공유
- 다른 브라우저 또는 다른 기기로 크랙 사이트 설정을 옮기는 기능을 추가합니다
- 이 확장은 GPT를 이용해 제작되었습니다.
- 다운로드 : https://github.com/hamster4762/crack-storage-bridge/raw/refs/heads/main/crack-storage-bridge.user.js

# 주의사항
- GM_setValue 데이터는 전송되지 않습니다. 확장이 GM 저장소와 웹 저장소를 함께 쓰면 일부만 복원되어 설정이 어긋날 수 있습니다.
- 선택한 Local Storage 항목은 덮어쓰기, IndexedDB는 DB 전체 교체됩니다.
- 복원 중 해당 사이트를 다른 탭에서 사용하면 데이터가 충돌할 수 있습니다. 다른 탭을 닫고 진행하세요.
- 중요한 데이터는 먼저 백업하세요.
- 최대 전송 용량은 약 40MB입니다.
- 링크는 10분간 유효합니다. 같은 LAN에서 링크를 가진 사람이 먼저 접속하지 않도록 공유에 주의하세요.
- 브라우저의 mDNS나 공유기 설정에 따라 연결이 간헐적으로 실패할 수 있습니다.
